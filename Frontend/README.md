# PROCUREMIND AI Frontend

AI-powered procurement intelligence landing page and frontend-only module previews, built with React, TypeScript, Vite, React Router, Recharts, Framer Motion, and Lucide.

## Getting started

```bash
npm install
npm run dev
```

The landing page is at `/`. Future module previews are available at `/dashboard`, `/negotiation`, and `/fraud-detection`. Their UI is illustrative; no backend or AI processing is connected.

## Build

```bash
npm run build
```
