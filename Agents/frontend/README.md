# Frontend (tahap berikutnya)

Direkomendasikan React + Vite + TypeScript. Layar MVP:
1. Ringkasan PO dan draft negosiasi (accept/revise/reject setelah login)
2. Fraud alert inbox (indikator, bukti, status investigasi)
3. Approval queue (dua pihak berbeda untuk perubahan kritis)
4. Audit trail (read-only)

Saat ini **belum ada aplikasi frontend**. Endpoint `/demo/*` hanyalah demo sintetis tanpa login; jangan dipublikasikan.
